# 词伴（CiDarenBuddy）完整使用说明

版本：0.1.0（测试版）  
适用平台：iPhone，iOS 27 或更新版本  
安装包：`CiDarenBuddy-unsigned.ipa`（未签名）

## 1. 应用用途

词伴用于在学习时查看屏幕上的中英文内容。它通过 iOS 系统屏幕共享接收屏幕帧，在本机使用 Apple Vision 做文字识别，并使用 Apple Translation 翻译。它提供实时识词、生词本和拼写练习。

词伴是独立应用，不需要登录微信或词达人账号，也不连接词达人内部接口，不代替用户答题或提交答案。画中画窗口显示最近识别的原文和译文；译文不会覆盖或嵌入微信页面。

## 2. 安装前准备

- iPhone 系统版本为 iOS 27 或更新版本。实时屏幕采集使用 iOS 27 的 ScreenCaptureKit 接口。
- 一台 Windows 10/11 电脑，用于给未签名 IPA 签名并安装。
- Sideloadly Windows 版，以及一条可传输数据的 USB 连接线。
- 一个用于个人侧载签名的 Apple ID。

本测试版已在 GitHub Actions 的 Xcode 27 / iOS 27 SDK 环境完成编译、打包和 IPA 结构检查；没有在真机上完成运行验证。

## 3. Windows 安装步骤

1. 从仓库 Releases 下载 `CiDarenBuddy-unsigned.ipa`。
2. 从 [Sideloadly 官网](https://sideloadly.io/)下载并安装 Windows 版。若 Windows 无法识别 iPhone，按 Sideloadly 的安装指引安装其要求的 Apple 设备驱动组件。
3. 用 USB 连接 iPhone 和电脑，解锁 iPhone。在手机提示中选择“信任此电脑”。
4. 打开 Sideloadly，将 `CiDarenBuddy-unsigned.ipa` 拖入应用窗口。
5. 选择已连接的 iPhone，填写你自己的 Apple ID，然后开始签名安装。Apple ID 凭据应只填写在你运行的签名工具中，不要发送给项目维护者。
6. 如果 iOS 要求开发者模式，打开“设置 → 隐私与安全性 → 开发者模式”，按提示重启并确认。
7. 如果系统提示开发者未受信任，打开“设置 → 通用 → VPN 与设备管理”，选择对应开发者并信任。
8. 在主屏幕启动“词伴”。

免费个人开发者签名通常有有效期限制，Sideloadly 官方说明为 7 天；到期后需要使用同一 Apple ID 重新侧载。付费开发者账号的签名期限和规则以 Apple 当前政策为准。

## 4. 首次使用与实时翻译

1. 打开“实时识词”页，在“翻译方向”中选择“译成中文”或“译成英文”。
2. 点“开始实时读屏”。
3. iOS 弹出系统屏幕共享选择器后，选择整个屏幕并确认开始共享。屏幕顶部或系统界面会显示屏幕共享状态。
4. 回到词伴点“开启译文小窗”。等画中画窗口出现后，切换到微信词达人或其他学习页面。
5. 词伴会不断处理屏幕共享流中的画面。识别到的文本和翻译结果显示在词伴页面；画中画窗口显示最近一条识别内容。
6. 使用完成后，返回词伴点“停止屏幕共享”，或通过 iOS 的屏幕共享系统控制结束共享。需要时点“关闭小窗”。

屏幕内容快速变化、字体很小、动画、低对比度或遮挡都会降低识别准确率。横屏、滚动和弹出的系统界面也可能改变识别顺序。

## 5. 查词与拼写练习

### 查词并加入生词本

1. 在实时识词页面等英文句子出现。
2. 点句子下方的英文单词按钮。
3. 弹出的卡片会显示中文释义；首次查询需要等待系统翻译结果。
4. 点“加入拼写练习”。词条保存在本机生词本中。

目前单字符英文不会生成单词按钮。生词本位于“生词本”页，可查看词条、释义和上下文；点“编辑”后可删除词条。重复添加同一个单词会更新已有释义和上下文。

### 拼写练习

1. 先至少向生词本添加一个英文词。
2. 打开“拼写”页，页面随机选取一个词并显示中文释义或上下文。
3. 在输入框填写英文拼写，点“检查拼写”或提交键。
4. 答对后计数增加，短暂显示结果后自动进入下一词；答错后可以继续尝试，系统可能给出最多三个拼写建议。

答案判定不区分大小写，但需要单词字母拼写一致。当前不会将练习结果上传或同步到其他设备。

## 6. 延迟和识别范围

iOS 系统控制实时采帧节奏。应用没有设置固定的 20 ms 帧间隔，因此 20 ms 不是本版本的采帧承诺，也不是端到端翻译时延保证。状态栏显示的是帧到 OCR 完成耗时，不包含等待屏幕新帧、系统调度和 Apple Translation 的耗时。真机上的完整响应时间需要针对具体画面、网络/语言资源状态及设备实测。

为避免积压旧画面，应用在上一帧 OCR 完成前会跳过新到帧。翻译通过 Apple Translation 执行；首次使用时系统可能需要准备对应语言资源。实际可用语言和资源状态以 iOS 系统为准。

## 7. 隐私与本地数据

- ScreenCaptureKit 画面只在处理过程中保留在内存中，本应用不写入照片库，也不生成录屏文件。
- 识别文本和翻译文本用于当前界面显示。
- 生词、释义、上下文和答错次数通过 `UserDefaults` 保存在本机应用数据中。
- 源码不包含向项目服务器上传屏幕帧、生词或练习记录的功能。
- iOS 系统可能显示其自己的屏幕共享提示与控制界面；停止共享可随时从词伴或系统控制操作。

卸载应用会清除与应用相关的本地数据；建议在删除应用前自行记录希望保留的词条。

## 8. 常见问题

### 点击开始后没有识别文字

确认 iOS 已同意系统屏幕共享，并且系统状态显示共享正在进行。切换到包含清晰文字的页面，保持应用没有被系统停止。屏幕共享选择器被取消时，重新点“开始实时读屏”。

### 系统提示屏幕采集不可用

确认设备运行 iOS 27 或更新版本，并在系统选择器中主动选择整个屏幕。当前版本依赖 iOS 27 的 ScreenCaptureKit 全屏共享接口。

### 画中画没有出现

先点“开启译文小窗”，等待状态变化后再切换应用。检查 iOS 的画中画功能是否可用；若仍不出现，先停止并重新开始屏幕共享，再重新开启小窗。

### 显示“翻译暂不可用”或查词失败

检查 iOS 当前可用的 Apple Translation 语言资源，确认所选方向符合屏幕文字语言，并稍后重试。系统可能需要准备语言资源。OCR 识别不清时，先检查原文是否出现在识词卡片中。

### 识别文本顺序不对或内容不全

当前版本按识别框的位置排列文本，复杂的多栏页面、竖排文字、小字体和动画页面可能造成顺序偏差。可尝试放大页面、暂停滚动或等待画面稳定。

### 重新安装后提示应用过期

个人免费签名有期限。使用同一 Apple ID 通过 Sideloadly 重新签名并安装 IPA。请确认重装使用相同应用标识，避免本地生词数据被新应用身份隔离。

## 9. 已知限制

- 要求 iOS 27 或更新版本；旧系统不能使用此版本的实时屏幕采集功能。
- 本项目只有 CI 编译和 IPA 打包验证，尚无已完成的真机验收结果。
- 屏幕采集频率由 iOS 调度，端到端 20 ms 延迟未实现为保证。
- 画中画展示最近一条文本，不会逐行叠加在其他应用上。
- OCR、翻译质量、画中画可用性和屏幕采集行为受 iOS、设备状态和具体页面影响。
- 生词本只保存在本机，没有云同步、导出或账号系统。

## 10. 从源码构建

### GitHub Actions

仓库的 `Build unsigned iOS IPA` 工作流在向 `main` 推送或手动触发时运行。成功后可在工作流运行页面下载 `CiDarenBuddy-unsigned-ipa` artifact；发布版本也会附带 IPA。

### 本机 Xcode

需要 macOS、Xcode 27 / iOS 27 SDK 与 XcodeGen：

```sh
brew install xcodegen
xcodegen generate
xcodebuild -project CiDarenBuddy.xcodeproj \
  -scheme CiDarenBuddy \
  -sdk iphoneos \
  -configuration Release \
  -derivedDataPath build/DerivedData \
  CODE_SIGNING_ALLOWED=NO build
```

工作流生成未签名 IPA；需使用个人 Apple ID 或开发者证书签名后再安装。签名凭据不保存在仓库或工作流中。

## 11. 版本与校验

当前公开版本为 `v0.1.0`。IPA SHA-256 校验值见仓库的 `SHA256SUMS.txt`，下载后可在 Windows PowerShell 中执行：

```powershell
Get-FileHash .\CiDarenBuddy-unsigned.ipa -Algorithm SHA256
```

将结果与校验文件中的值比较即可确认下载文件完整。
